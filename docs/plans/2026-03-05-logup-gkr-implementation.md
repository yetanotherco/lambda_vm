# LogUp-GKR Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace committed LogUp auxiliary traces with a GKR interactive proof, eliminating 55 aux columns across 12 tables and reducing them to 1 Lagrange kernel column per table.

**Architecture:** The GKR sub-protocol runs after main trace commitment and LogUp challenge sampling (Phase B'). It proves the LogUp sum identity via a fractional-sumcheck over a binary summation tree. MLE evaluation claims are bridged back to committed univariate traces via a Lagrange kernel (eq-weight) column and composition polynomial quotient terms.

**Tech Stack:** Rust, Goldilocks field (u64) with cubic extension, Rayon parallelism, existing STARK framework in `crypto/stark/`.

**Design doc:** `docs/plans/2026-03-05-logup-gkr-design.md`
